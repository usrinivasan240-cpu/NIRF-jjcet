Purpose

NIRF ERP and the information each report should contain. All reports
must be generated dynamically from the database.

3. Department Annual Report

Dynamic: - Faculty Summary - Student Summary - Research Output -
Publications - Patents - Consultancy - Placement Statistics - Higher
Studies - Infrastructure - Events - Budget Summary - Target
Achievement - Document Verification Common: - Header, Footer, QR,
Remarks, Signatures

5. Publication Report

Dynamic: - Journal - Conference - DOI - ISSN - Authors - Department -
Year - Indexing - Citation Count - Verification Status

7. Consultancy Report

Dynamic: - Company - Project - Faculty - Amount - Duration - Status -
Completion

9. Student Achievement Report

Dynamic: - Projects - Internships - Certifications - Hackathons -

11. NAAC Report

Dynamic: - Criterion-wise Data - SSR Summary - AQAR Data - Supporting
Documents - Department Contributions

13. IQAC Report

Dynamic: - Academic Audit - Quality Initiatives - Feedback - Action

15. Target Achievement Report

Dynamic: - KPI - Annual Target - Current Achievement - Pending -
Completion % - Status

Common Elements (All Reports)

-   JJCET Logo
-   College Name
-   Report Title
-   Academic Year
-   Report ID
-   Generated Date & Time
-   Generated By
-   Department Name (if applicable)
-   QR Code
-   Footer
-   Version Number
-   Confidential Notice
-   Empty Remarks (HOD / VP / Principal where applicable)
-   Empty Signature Boxes
-   Print-ready A4 Layout

Database-Driven Fields

The following must always be dynamic: - Faculty Data - Student Data -
Department Data - Publications - Patents - Consultancy - Research
Projects - Grants - Placements - Higher Studies - Events - Targets -
Achievements - Pending Items - Approval Status - Verification Status -
Generated Date & Time - Report ID - QR Code

No report should contain hardcoded numbers or dummy data. Every value
must be fetched and calculated from the ERP database.
